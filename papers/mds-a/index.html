Multiple Distribution Shift-Aerial (MDS-A): A Dataset for Test-Time Error Detection and Model Adaptation

Noel Ngu, Aditya Taparia, Gerardo I. Simari, Mario A. Leiva, Ransalu Senanayake, Paulo Shakarian, Nathaniel D. Bastian, John Corcoran

Proceedings of the AAAI Symposium Series, 2025

picture_as_pdf PDF

Summary

We present MDS-A, a dataset of simulated aerial imagery paired with explicitly controlled distribution shifts, built for evaluating test-time error detection and model adaptation methods under conditions where a single held-out test set would not expose failure.
